# RISC-V Processor Design

A five-stage pipelined RISC-V processor implemented in Verilog as part of Georgia Tech's CS 3220 processor design coursework.

The project explores processor microarchitecture, instruction execution, pipeline hazards, data forwarding, and dynamic branch prediction.

## Project Organization

**The final and most complete implementation is located in the [`project_4`](./project_4) directory.**

The other project directories contain earlier stages of development and coursework leading up to the final implementation.

For the completed processor architecture, including the five-stage pipeline, data forwarding, and branch prediction logic, refer to `project_4`.
